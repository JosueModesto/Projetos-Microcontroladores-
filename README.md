# Projetos de Automação com Arduino

Este repositório reúne dois projetos desenvolvidos utilizando **Arduino e programação em C/C++**, com foco em automação, sensores, atuadores e controle de processos.

Os projetos foram desenvolvidos como atividades acadêmicas e contam com simulações para demonstrar seu funcionamento.

## 📦 Projetos

### ⚖️ Balança e Dispenser Automático

Sistema desenvolvido para realizar a **medição de peso e controle de um dispenser automático**.

O projeto utiliza uma célula de carga com o módulo **HX711** para realizar a leitura do peso e um **servo motor** para controlar o mecanismo de dispensação.

#### Principais funcionalidades

* Leitura de peso utilizando HX711;
* Calibração da balança;
* Medição da quantidade dispensada;
* Controle de servo motor através de PWM;
* Definição de uma quantidade desejada em gramas;
* Acionamento através de botões;
* Comunicação e interação através da porta serial.

#### Tecnologias

* C/C++
* Arduino
* HX711
* Célula de carga
* Servo motor
* PWM / Timer1
* Comunicação Serial

🔗 **Simulação no Wokwi:**
https://wokwi.com/projects/381667174168707073

### 🍞 Panificadora Automática

Projeto de automação de uma **panificadora**, desenvolvido utilizando Arduino e componentes eletrônicos simulados.

O sistema tem como objetivo controlar automaticamente as etapas do processo de preparação, utilizando sensores, atuadores e lógica de controle para executar as funções programadas.

#### Principais conceitos utilizados

* Programação em C/C++;
* Controle de entradas e saídas digitais;
* Acionamento de componentes;
* Automação de processos;
* Leitura de sensores;
* Controle de etapas de funcionamento.

🔗 **Simulação no Tinkercad:**
https://www.tinkercad.com/things/kBStNgXXifW-panificadora

## 🎯 Objetivo do Repositório

O objetivo deste repositório é documentar projetos de **programação embarcada e automação**, demonstrando conhecimentos em programação C/C++, microcontroladores, sensores, atuadores e desenvolvimento de sistemas automatizados.

Os projetos também fazem parte do portfólio acadêmico na área de **Ciência da Computação e Desenvolvimento de Software**.
